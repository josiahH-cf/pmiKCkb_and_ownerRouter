# PMI KC KB

PMI KC KB is the shared production application shell.

## Current capability

- Managed-domain sign-in and server authorization.
- Console and notifications.
- Source-backed Ask with citations and explicit missing-source states.
- Spaces and process definitions.
- Approval and action execution boundaries.
- Lease Renewal, Maintenance, Workflow Communications, Admin, feedback, resident/Vendor seams, and
  staff work.
- Eleven configured production Spaces.

Production is Live-only. An unbacked compatibility Space is hidden from normal directories. Local
rehearsal may inspect bounded live reads but cannot persist or invoke providers.

The KB never invents client policy. Unsupported answers say that a reliable source is missing and
route the gap for human follow-up.
