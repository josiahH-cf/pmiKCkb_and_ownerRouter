## Remaining blockers

- **L28, owner decision Q1.** S235 R-S235-2 requires the renewal packet policy default to be
  labeled "Engineering default, not yet approved by the client"; the Admin packet policy field
  shows "Engineering default, not yet approved by the client. An Admin records the client's
  decision." S244 and L28 forbid hold phrasing in inline helper copy. Which rule governs this
  hint? If S244 governs, the proposed present-tense wording is "Engineering default. An Admin
  records the client's decision here.", with R-S235-2 amended to match.
- **L28, engineering approval Q2.** The S244 copy inventory (`scripts/lib/help-copy-inventory.mjs`)
  does not collect texts in conditional branches, so 71 in-scope helper texts (including the three
  repaired ones) have no disposition row, and the disposition test refuses rows the inventory
  does not produce. May a follow-up extend the inventory to conditional branches, a stricter gate,
  and add those rows? This run changed no gate.
- **L10, evidence gap.** 16 guide-step results need provider results or connections the
  rehearsal refuses by design (the RentCast report, Sheet and RentVine apply and reconcile, the
  rent charge preparation, Gmail send, status check and sequence resume, the RentVine connection
  check, and the Dotloop connection, refresh, profile, template and selection). 18 need synthetic
  states or interactions this run did not seed or perform (an assigned My Work task for start,
  pause, complete, block and correct; unread notifications; a second page of search results, the
  suggestion list and a related-records entity; an assignable queue item and a pending access
  request; an operational page to publish and to read; a role change; a delivered tenant offer; a
  saved Communications draft; future-rent preparation; the Admin-only resource link save). Seeding
  those states resolves the second group; the first needs a provider test double or a human run.
