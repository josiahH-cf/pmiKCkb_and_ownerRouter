How the spreadsheet rehearsal works

  1. Admin verifies that the operating Sheet and rehearsal copy have different file ids.
  2. The operator selects one exact blank cell in the copy. A nonblank cell causes an immediate stop.
  3. The tool writes one clearly synthetic marker to that copy cell.
  4. It reads the cell back and requires an exact match.
  5. It removes only that exact marker and reads the cell back blank.
  6. The operator separately opens both links and confirms that the operating Sheet did not change.

A passing test requires the copy to be restored. A write without its readback and cleanup is a failed test.

How we will discuss data differences

The read-only audit found 20 High current-rent conflicts. That count is a review queue—not proof that 20 RentVine records are wrong.

Category Plain meaning What happens next
Sources agree RentVine and the Sheet describe the same fact. No correction.
Sources conflict Both have a value, but the values differ. A person chooses the correct source or enters a correction.
RentVine only RentVine has the fact; the Sheet does not. Decide whether the Sheet should track it.
Sheet only The Sheet has the fact; RentVine does not. Confirm whether it is work-in-progress or missing source data.
Missing Neither source has a usable fact. Request the information; do not guess.
Intentional difference The sources measure different things—for example base rent versus total charge. Document the definition and stop treating it as an error.
Stale snapshot One source may simply be older. Refresh and compare again before deciding.
Identity unclear The app cannot prove both rows refer to the same lease. Match the record manually; never merge by guess.
