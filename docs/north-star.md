# North star

PMI KC should make operational work clearer and safer without inventing policy or hiding uncertainty.

## Product outcomes

- Staff can see what needs attention and why.
- Lease renewal work is organized around authoritative provider ids and current evidence.
- Source conflicts are explicit and actionable.
- Communications remain attached to workflow context and human review.
- External effects are narrow, reversible, and provable.
- Missing inputs degrade visibly instead of creating fake completeness.
- Admin can understand connections, gates, and ownership without technical translation.

## Non-goals

- Autonomous client messaging.
- Generic blast email.
- Unreviewed provider writes.
- Product Demo/Test data in Production.
- Employee surveillance or productivity scoring.
- Guessing legal, pricing, recipient, or process policy.
- Hiding unfinished provider seams behind sample success.

## Measure of done

A feature is done when its real behavior is built to the external seam, adversarially tested,
documented as present truth, deployed when applicable, and honest about its one exact remaining
dependency.
